# FlyBrain Arena：当前版本

本页是 Windows 版的简明使用说明；进度、证据和遗留问题以根目录 `STATUS.md` 为准。

## 启动与操作

在仓库根目录执行 `powershell -ExecutionPolicy Bypass -File .\run.ps1`。
启动器为本次运行生成临时口令、选择本地端口，并启动自己的 Python/Godot 子进程；无需把口令写进文件。
已有游戏正在运行时，启动器的单实例检查会退出。更新代码后请从旧窗口正常退出，再重新启动。

| 操作 | 按键 |
| --- | --- |
| 移动、瞄准 | WASD、鼠标 |
| 射击 | 鼠标左键 |
| 手电 | F |
| 脑活动面板、详细检查 | B、V |
| 指标、暂停 | Tab、Esc |

Drone 满血 100，单发固定 15 点，命中 7 枪击倒；冷却 0.35 秒、射程 25 m。
射线由墙体阻挡，Drone 接触玩家即结束回合。当前速度上限 6.4 m/s、加速度上限 19.2 m/s²。
桌面战斗已接通；触屏移动/视角仍兼容，但触屏开火尚未实现，不把移动端布局回归等同于完整触屏战斗支持。

## 神经闪避的含义

威胁传感器从预瞄及开火、射线距离和遮挡构建输入，直接激励真实 LC4/LPLC2 群组。
原有完整 MaleCNS 图传播后读取 DNp01/DNp03，双侧活动差参与 Drone 闪避方向。
没有“已命中后撤销伤害”的机制，也没有把背景随机飞行称作神经闪避。

连接与神经元身份来自数据集；传感编码、signed-rate 动态、输出到飞行的映射都是工程规则。
当前实现不是生物视网膜、校准过的生物时间模型或真实飞行动力学。
局部切除候选连接会显著压低逃逸读出；左右输入在真实后端和生产客户端中产生相反方向。
事件层学习与这条通路分开，未宣称学习改变了连接组本身。

## 视听反馈

- 命中出现短暂青色标记；落空不显示命中确认。
- 开火、命中、胜负有各自的短音效，Drone 使用原创机械旋翼循环。
- 所有声音遵循原有音量与静音。暂停、重开清理残留反馈。
- 命中标记、音效不改变射线、碰撞、伤害或神经状态。

## 验证与回滚

`powershell -ExecutionPolicy Bypass -File .\test.ps1 -SkipSmoke` 运行 Python 和离线 Godot 检查；
去掉 `-SkipSmoke` 会额外启动真实战斗 smoke，需先正常退出占用启动器的游戏。
headless 不适合做主观音色、手感或渲染性能验收；这些仍需窗口试玩。

P3 证据在 `reports/p3-neural/`，P4 证据在 `reports/p4-feedback/`。
每阶段的 `rollback.py` 默认只校验，加 `--apply` 才恢复；脚本核对 SHA256，检测到后续修改会停止。
恢复阶段顺序是先 P4、再 P3。请先备份自己后续编辑的文件，勿用回滚脚本覆盖新工作。
